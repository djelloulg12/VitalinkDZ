# رعايتي DZ — نبض الرعاية المتصل

منظومة وطنية موحدة للرعاية الصحية والاجتماعية والسياحة العلاجية — المكان الرسمي للمشروع الصحي
(FastAPI + React/Vite + SQLite، بنفس التصميم البنفسجي و Readex Pro المحلي و RTL للـ واجهة).

```
رعايتي/
backend/     FastAPI (async) — دوارات: auth, wilayas, institutions, staff, referrals, followups,
                associations, gps, shifts, zones, agencies, thermal, drugs, about, admin, audit,
                predict (الإنذار التنبؤي) + crypto (AES-256-GCM) + tools/backup
   frontend/    React 18 + Vite + TS — نظام تصميم بنفسجي/أبيض، Readex Pro محلي، RTL، PWA
  data/        vitalink.db (SQLite — تُنشأ وتُبذر تلقائياً عند الإقلاع)
```

## تشغيل المنصة

```bash
# 1) الخلفية (المصرف 8100)
cd backend
uvicorn app.main:app --host 127.0.0.1 --port 8100

# 2) الواجهة (المصرف 5173 — يعمل proxy إلى 8100)
cd frontend
npm install
npm run dev
```

افتح: **http://localhost:5173** — واجهة عامة: `/about` (من نحن) و `/public/associations` (الشفافية).
تطبيق الهاتف (PWA): `/vital` — الإعداد للمزامنة Offline-First والتثبيت عبر شريط المتصفح.

## الوحدات المنجزة

1. **لوحة المدير الوطني**: إحصاءات موسّعة (إحالات حمراء، ملفات متابعة، نوبات، حجوزات…) + تنبيهات ذكية + شريط جوال + سجل عمليات (Audit).
2. **الكوادر والتراخيص**: بطاقات + **تحقق من ترخيص الممارسة (قانون 18-07)** بتوثيق المدير ومساره، بطاقة تعاقد رسمية للطباعة، CSV.
3. **الإحالة الإلكتروني**: حالات + severity + **RED ALERT** (رد خلال 6 ساعات للطارئة / 48 للعادية) + **SLA** + ربط المؤسسات + وثيقة رسمية + CSV.
4. **ملفات المتابعة (القسم 5)**: تدوينات/قياسات/زيارات مع **مؤشرات حيوية ومرفقات (base64) وتوقيع اعتماد**، **Offline-First**: قائمة محلية في `localStorage` + مزامنة push/pull + طباعة وCSV.
5. **نقاط الجمعيات**: ترتيب، تقييم ميداني (نقاط = زيارات×10 + متطوعين×5 + أنشطة×40 + أثر×150) + **سلم مكافآت** (منقذ ذهبي/شريك مميز…) + **لوحة شفافية عامة** + تقرير رسمي + CSV.
6. **نوبات العمل**: جدولة نوبات (فريق متحرك متاح 24س) + أسبوع/مناوبات.
7. **وكالات السياحة (بوابة)`agency_1`**: ملف، **أسطول+مرشدون+حزم**، **ربط إحالة طبية بحزمة سياحة علاجية**.
8. **السياحة العلاجية (بوابة)`thermal_1`**: محطات حموية + حزم + **اقتراح مسار (AI بقاعدة معرفة)** مع استبعاد لافتات الخطر + **موافقة الطبيب قبل السفر** + حجوزات/تأمين + تقييمات + تقارير.
9. **الأسوار الجغرافية (Geofencing)**: نطاقات دائرية + **فحص نقطة (lat/lng) داخل/خارج السور** للممرض المتنقل + المحطات الحموية بالإحداثيات.
10. **التداخل الدوائي**: قاعدة معرفة (وارفارين/أسبرين، ديجوكسين/أميودارون، ليثيوم/مضادات…) بمستويات تحذير ونصائح.
11. **من نحن والسيرة (صفحة الباحثة)**: محتوى قابل للتحرير (`about`/`researcher`) ظاهر للعموم.
12. **تطبيق Vital DZ (PWA — القسم 9)**: قياس المؤشرات (نص/صوتي) مع **تخزين محلي عند الانقطاع والمزامنة**، **SOS عبر SMS بموقع GPS دون إنترنت**، تذكير أدوية ذكي يعمل محلياً، الفريق الطبي بترخيص الموثق، بطاقة مريض QR، وتسجيل Service Worker (ثبات/كاش).
13. **الأمان والحيوية (المرحلة الجديدة)**:
    - **تشفير عند التخزين AES-256-GCM**: الملاحظات والقياسات السرية تُشفر (المفتاح في `data/.enc_key` أو متغيّر `VITALINK_ENC_KEY`)، مع توافق رجعي كامل للبيانات القديمة وفك تلقائي عند العرض.
    - **محرك الإنذار التنبؤي** `vital_alerts`: يحلل المؤشرات (نبض/ضغط/أكسجين/حرارة/سكر) عند كل تسجيل ويولّد إنذارات info/warning/danger مع **منع التكرار** + إقرار من الطبيب + `/api/alerts/check` فوري + `/api/alerts/today`.
    - **بوابة العائلة** `/portal/family` (`family_1`): هوية كبار السن (أزرق داكن/أخضر، أزرار ≥54px)، أحدث القياسات، التنبيهات، فريق الرعاية، بطاقة QR، وزر SOS.
    - **نسخ احتياطي يومي مشفَّر**: `python -m tools.backup` من `backend` (أو `POST /api/admin/backup`) + عرض القائمة `GET /api/admin/backups`، التشفير AES-256-GCM.
    - **مزامنة Offline-First عبر IndexedDB**: `frontend/src/offline/sync.ts` (وضع للرفع عند عودة الاتصال) بدّل قائمة `localStorage` في تطبيق Vital DZ.
    - **مخطط PostgreSQL** المقترح للترقية: `backend/postgres_schema.sql` (Users/HealthProfiles/Referrals/MedicalNotes + RBAC + سجل التدقيق + نسخ مشفر).
    - **نموذج تصميم النموذج الأولي لكبار السن**: `prototype/vitaldz-senior.html` (نظام صفحة واحدة بدون SDK: أزرار عملاقة، SOS مع الموقع).
14. **المرحلة 2α — الرعاية المستمرة**: روشتات إلكترونية موقّعة (إصدار/صرف بضبط المخزون + إعادة تزويد)، **كسر الزجاج الطارئ** (OTP + سجل/إطلاق)، **موافقات رقمية قابلة للإلغاء**، **خطط ما بعد العلاج بغايات وجدول**، **الصحة النفسية** (فحص PHQ/GAD + عبء مقدم الرعاية Zarit + جلسات) مع بوابات: **مستفيد، صيدلي، ممرض متنقل، طبيب/مستشفى، والعمليات الصحية** (`/admin/healthops`).
15. **تطبيق الرفيق (أندرويد + iOS)** عبر **Capacitor** من نفس كود الويب: **زر SOS عملاق** يثبّت الموقع بدقة قبل الإرسال، **نبض حضور دائم** كل 60 ثانية (`/api/presence`) مع الموقع الحالي، Geofence/GPS النظام أصلياً، إعداد خادم داخل التطبيق، ومشروع `frontend/android/` جاهز للبناء (`npm run cap:android`؛ iOS يُولَّد على ماك).

## طباعة رسمية
